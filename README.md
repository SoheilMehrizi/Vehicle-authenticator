# Vehicle-authenticator
A Controlling System that authenticates authorized vehicles by their licence plate 

## 1. Project Overview  
**Vehicle Authenticator** is a smart entrance control system that combines object detection, OCR, a web API, and IoT to grant access only to authorized vehicles. When a vehicle approaches, the system detects its license plate, reads it via OCR, checks against a database, and—if authorized—signals an Arduino-controlled gate to open.

---

## 2. Key Features  
- **Vehicle Management (CRUD)**  
  Create, Read, Update, and Delete vehicle records via a RESTful API.

- **License Plate Recognition**  
  - Real-time vehicle detection using YOLOv8.  
  - OCR on detected plates via EasyOCR.  

- **Authorization Logic**  
  Validates plate numbers against a Redis-backed database.

- **IoT Gate Control**  
  Sends open/deny signals to an Arduino UNO when authorization succeeds or fails.

- **API Documentation**  
  Interactive Swagger UI autogenerated by FastAPI.

---

## 3. Tech Stack  
- **FastAPI** — high-performance Python web framework for the REST API  
- **YOLOv8** — real-time object detection model for vehicles/plates  
- **EasyOCR** — optical character recognition on detected plates  
- **Redis** — in-memory database for rapid plate‐lookup  
- **Arduino UNO** — microcontroller that receives open/deny commands and drives the gate  
- **Docker & Docker Compose** — containerization and orchestration  

---

## 4. Prerequisites  
- Docker & Docker Compose installed on your host machine  
- Arduino UNO (with USB connection) and requisite drivers installed  
- A 12 V power supply for the gate mechanism  

---

## 5. Installation & Setup  

1. **Clone the repository**  
```
   git clone https://github.com/SoheilMehrizi/Vehicle-authenticator.git
   cd Vehicle-Authenticator
```

Build and start services

```
docker-compose up --build
```
 This will launch:

FastAPI server (HTTP port 8000)

Redis instance (port 6379)

YOLO/EasyOCR workers for plate detection and OCR

**Connect Arduino UNO**

**Plug the Arduino UNO via USB.**

Verify the device node (e.g. /dev/ttyACM0 on Linux or COM3 on Windows).

## 6. Usage
Explore the API
Navigate to http://localhost:8000/docs for the Swagger UI.

1. POST /vehicles/ – Add a new authorized vehicle

2. GET /vehicles/ – List all vehicles

3. GET /vehicles/{plate} – Retrieve a vehicle by plate number

4. PUT /vehicles/{plate} – Update vehicle info

5. DELETE /vehicles/{plate} – Remove a vehicle


The system captures a frame, detects the plate, performs OCR, and queries Redis.

If authorized, the Arduino gate controller raises the barrier.

## 7. Deployment
This project is fully Dockerized. To deploy in a production environment:

Ensure your host has Docker and Docker Compose.

Configure any production-specific environment variables in .env.

Run:
```
docker-compose -f docker-compose.prod.yml up --build -d
```
